# -PrecisionChurn-Customer-Churn-Prediction-Using-Stacked-Ensemble-Learning-
**PrecisionChurn is a customer churn prediction system built using a stacked ensemble of XGBoost, LightGBM, and CatBoost with a Logistic Regression meta-model. It incorporates feature engineering, cross-validation, class imbalance handling, and threshold optimization to deliver high-precision churn risk predictions.**
